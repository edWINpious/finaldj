# Team Handoff Pack

Start with `HANDOFF_FINAL.md` --- authoritative project specification
and easy stack recommendation.

Each teammate gets their own folder: - `01_SSH/context.md` and
`01_SSH/claude.md` - `02_WEB/context.md` and `02_WEB/claude.md` -
`03_DATABASE/context.md` and `03_DATABASE/claude.md` -
`04_ATTACKER/context.md`, `04_ATTACKER/claude.md`, and
`04_ATTACKER/attacker_handoff.md`

Give each Claude Code session its module `context.md`, module
`claude.md`, and the root `HANDOFF_FINAL.md`. Ask it to complete Phase 1
only, review the plan, then authorize each next phase.

Stack: Python 3.12, Docker Compose, Cowrie, FastAPI, MariaDB, SQLite,
Streamlit + Plotly, Pydantic, pytest. Keep the central
collector/schema/dashboard under one designated integrator.
